# Generative Music in Python

A learning journey: from fractals to a **three-voice fugue with modulating episodes**, plus three free-style pieces (**George Winston**, **Kitaro** and **Yanni**), with export to **WAV, MP3 and MIDI**.

Everything is generated by code: nothing is recorded or composed by hand. Each piece is a program that decides notes, rhythms and structure (with rules and randomness controlled by a *seed*) and then synthesizes the audio with NumPy and SciPy.

> **About this translation.** This is the English version of `README_es.md`. The code itself — identifiers, comments and console messages — is in Spanish, and so are the names of the output files. This README keeps the Spanish names exactly as they appear in the code; the section "Spanish terms in the code" at the end of the study guide gives the English equivalents.

## Installation and running

Tested with Python 3.12.3, NumPy 2.4.4, SciPy 1.17.1, lameenc 1.9.0 and mido 1.3.3.

```bash
pip install numpy scipy lameenc mido
```

```bash
python fuga.py              # exposition → fuga.wav
python fuga_larga.py        # + variations → fuga_larga.wav and .mp3
python fuga_episodios.py    # complete fugue with episodes → .wav and .mp3
python winston.py           # ≈ 2 min of audio
python kitaro.py            # ≈ 3 min of audio; takes about 1 minute
python yanni.py             # ≈ 2 min 20 s of audio; takes about 40 s
python midi_export.py       # fugue (3 versions), Winston and Yanni → .mid
python fuga_stretto.py                  # ≈ 12 s; --dmin 2 --dmax 3 (default) sets which delays it allows
python fuga_tonal.py                    # ≈ 5 s: fugue with modulation to A minor
python sonidos_naturales.py             # ≈ 47 s for all 13; or: python sonidos_naturales.py rio tormenta --dur 120
python sonidos_meditativos.py           # ≈ 26 s for the 5
python verificar_sonidos.py             # ≈ 58 s; prints 15/15 if all goes well
```

> The times are those measured in the test environment; they will vary on another machine. `midi_export.py` generates the MIDI files of the earlier fugue; `fuga_stretto.py` and `fuga_tonal.py` write their own when they run.

**Reproducibility:** all randomness comes from `numpy.random.default_rng(semilla)`. With the same seed and the same NumPy version the same piece should come out; across NumPy versions this is not guaranteed.

**Seeing the fugue written out:** open the `.mid` files in MuseScore Studio. Each voice is a track, so the sequences, the cadences and the entries of the subject are visible.

## What each piece does

- **Fugue (`fuga.py`, `fuga_larga.py`, `fuga_episodios.py`).** In D minor, in three voices. The exposition presents the subject, the answer at the fifth and the countersubject. `fuga_larga.py` adds entries with the subject inverted and augmented. `fuga_episodios.py` builds the complete form: exposition, modulating episode to F major, entries in F, return episode and final entries in D minor. The counterpoint is not loose randomness: it is **searched for** with rules (consonance, no parallels, limited leaps) and checked at the end.
- **Winston (`winston.py`).** Slow Am–F–C–G progression, continuous left-hand arpeggio, spaced-out melody, sustain pedal, synthesized piano, A A′ B B′ A structure and ritardando.
- **Kitaro (`kitaro.py`).** Drone with detuned oscillators, slow-attack pads over Dm9–Bbmaj7–Fmaj7–Cadd9, pentatonic flute with vibrato, a pizzicato pulse with ping-pong echo and a 5 s reverb.
- **Yanni (`yanni.py`).** Piano ostinato, melody with sequences, cello, strings, solo violin, timpani and cymbals, an ascending bridge that ends on the dominant of the new key, and a change from D minor to E minor.
- **Stretto (`fuga_stretto.py`).** Entries of the subject that begin before the previous one has finished. Not every subject will do: the program checks which ones allow a stretto with a short delay and builds the complete fugue with the one that does, with a three-entry stretto at the end.
- **Modulation to the dominant (`fuga_tonal.py`).** D minor → A minor → D minor, with episodes whose sequence crosses from one scale to another, entries of the subject in A minor (real transposition) and authentic cadences with a leading tone (G♯ and C♯). The notes are MIDI pitches, so accidentals fit.
- **Soundscapes (`sonidos_naturales.py`).** Water (physical bubble model), waves, gusty wind, soft rain, a storm that approaches, passes overhead and moves away (with thunder and moving panning), metal and wooden wind chimes, fire, dripping in a cave, crickets and a night-forest mix.
- **Meditative sounds (`sonidos_meditativos.py`).** Tibetan bowls (struck and rubbed), deep sea with optional whale calls, fractal noise whose spectral slope changes over time, and binaural and isochronic tones.

## Data formats (the key to everything)

**Musical time.** The unit is the quarter note, called a "beat" (`tiempo` in the code). A 4/4 bar is 4 beats; an eighth note is 0.5. To convert to seconds: `segundos(b, b0, bend)` in Winston and Yanni (it includes the ritardando) and `beat = 60 / bpm` in the fugue. Kitaro works directly in seconds.

**Pitch.**

- *Fugue:* diatonic degrees of D natural minor, as integers. `0` = D4 (MIDI 62), `1` = E4, `2` = F4, `3` = G4, `4` = A4, `5` = B♭4, `6` = C5, `7` = D5; negatives go down (`-7` = D3). `midi(grado)` converts them to MIDI. Transposing by degrees is adding an integer, and it **does not change the scale**: that is why the answer at the fifth is `+4` and the move to the relative major (F) is `+2`.
- *Winston, Yanni, Kitaro:* plain MIDI numbers (60 = C4, 69 = A4 = 440 Hz).
- *`fuga_tonal.py`:* MIDI pitches, not D-minor degrees, because it needs accidentals (G♯ and C♯ do not exist in D natural minor). `a_midi()` converts the voices of `fuga.py` to MIDI.

**Note and event.**
- *Fugue:* a voice is a list of `(grado, inicio, duración)` — (degree, start, duration) — and the work is `voces = {'soprano': [...], 'alto': [...], 'bajo': [...]}`.
- *`fuga_tonal.py`:* a voice is a list of `(altura_midi, inicio, duración)` — (MIDI pitch, start, duration); the work is still `{'soprano': [...], 'alto': [...], 'bajo': [...]}`.
- *Winston:* `(midi, inicio, duración_hasta_levantar_el_pedal, velocidad 0–1)` — (MIDI, start, duration until the pedal is lifted, velocity 0–1).
- *Yanni:* `(instrumento, midi, inicio, duración, velocidad, panorama_o_None)` — (instrument, MIDI, start, duration, velocity, pan or None).
- *Kitaro:* there is no common list of events: `componer()` places the signals in a buffer as it generates them.

**Position convention in the counterpoint.** `(voz, '<')` means "the new voice sits **below** that voice"; `'>'`, above.

**Scales and degrees in `fuga_tonal.py`.** `Escala(tonica, modo)`: index 0 is the tonic and `esc.midi(i)` gives the pitch of degree `i`. D minor is `Escala(62)` and A minor `Escala(69)`; the `'armonica'` mode raises the seventh degree (the leading tone). The voice that `contrapunto_tonal()` generates is made of **relative scale indices**: the final pitch is `esc.midi(g + despl)`, and each *scenario* can bring its own scale. `triada` is a set of pitch classes (modulo 12), not degrees: `{9, 0, 4}` is the A minor chord.

## 1. `winston.py`

**Flow:** `partitura()` → list of events → `render()` → WAV → `wav_a_mp3()`.

**Key concepts**
- **Melody as a weighted random walk** (`elegir_nota`): each candidate note receives a weight `exp(-distance/2)` (it prefers nearby notes), another that pulls it toward a central register, a ×0.05 penalty if it repeats the previous note and a ×1.6 bonus if it continues in the same direction. On strong beats only chord tones are allowed.
- **Variation by partial repetition** (`frase`, argument `base`): the second phrase copies three bars and recomposes only the last one.
- **Sustain pedal:** each note lasts until the end of its bar (`fin_pedal - inicio`).
- **Additive piano** (`piano`): a sum of 8 slightly inharmonic partials; high ones decay faster; low notes last longer; soft notes are less bright.
- **Humanization** (`render`): ±6 ms of offset on each attack and ±0.04 of velocity.
- **Ritardando** (`segundos`): the tempo slows down with a quadratic function between `b0` and `bend`.
- **Convolution reverb** (`reverb`): the impulse response is noise with exponential decay, smoothed with a one-pole filter.

**Suggested reading:** constants → `elegir_nota` → `compas_melodia` → `frase` → `partitura` → `piano` → `segundos` → `render`.

**Experiments:** change `BPM`; change `PROG` and add the new chord to `ACORDES`; raise the `0.05` repetition penalty and hear the melody stagnate; widen `REGISTRO`; change `rt60` in `reverb`.

**Questions:** why does `fuerte` require `d >= 1`? What would happen without the direction factor? How is the pedal effect achieved without a "pedal" variable? Why is `segundos()` quadratic and not linear?

## 2. `kitaro.py`

**Flow:** `componer()` builds separate buffers (pads, drone, flute, pulse), applies echo to the flute and the pulse, mixes, adds reverb and writes the WAV.

**Key concepts**
- **Detuned oscillators** (`pad`): each note is 3 sawtooth voices at −9, 0 and +8 cents, spread across the stereo field. The mix produces slow *beating*, which gives the feeling of a "chorus".
- **LFO that opens and closes the timbre:** the brightness `b` oscillates between two values; the amplitude of each harmonic is `amp *= exp(-1.2·(1−b))`, so with a high `b` more high harmonics appear. It is a moving low-pass filter made out of harmonics.
- **Flute** (`flauta`): vibrato by **phase modulation** (it appears after 0.5 s) and a breath of band-filtered noise.
- **Ping-pong echo** (`eco`): repetitions that alternate between left and right, each attenuated by `fb**i`.
- **Pentatonic melody** (`melodia`): one phrase per chord, with long notes and silences. The D minor pentatonic works over the four chords without clashes.
- **Long reverb** (`reverb`, `rt60=5`).

**Experiments:** change `brillo=(0.3, 0.8)`; change `CH` (duration of each chord) and `CICLOS`; try another `retardo` and `fb` in `eco`; replace `PENTA` with another scale.

**Questions:** why do three detuned voices sound "wider" than one? What is the difference between modulating the frequency and modulating the phase? Why is it mixed as `0.62·seco + 0.38·reverb` (0.62 dry + 0.38 reverb)?

## 3. `yanni.py`

**Flow:** `partitura()` → events with an instrument → `render()` (two buses, piano and orchestra, with different reverbs) → WAV.

**Key concepts**
- **Chords as (root, quality):** `(0,'m')` = D minor, `(-4,'M')` = B♭ major, etc. The root is expressed in semitones above D.
- **Melodic sequence** (`secuenciar`): repeats the shape of a bar over another chord, shifted `desplaza` scale degrees, and adjusts the strong beats to chord tones. It is the device that gives the feeling of "ascent" in the bridge.
- **4-bar phrase** (`frase`): motif, response, sequence of the motif and cadence.
- **Key change** (`SECCIONES`): the third element of each section is a transposition in semitones. The jump from D minor to E minor is `trans=2`.
- **Tension toward the change:** the bridge ends on B major (the dominant of E minor), with a timpani roll and a cymbal that grow until the crash.
- **Orchestration by section:** who enters and when is in `partitura()` (cello from the middle of A; strings and timpani from B; the whole ensemble in the final section).
- **Synthesized instruments:** `cuerda` (3 detuned voices with optional vibrato; it serves for violin, cello and ensemble), `timbal` (pitch sweep + noise hit), `platillo` (filtered noise with a crescendo).

**Experiments:** change `trans` in `final` and `coda` (3 = minor third); reverse the direction of `desplaza`; change `vel_arp` and the velocity dictionaries of `cuerdas` and `timbal` to regulate how much the ending grows; try another `semilla` in `partitura`.

**Questions:** why does the bridge melody use only chord tones in the last bar? What does `es_fuerte` do and why does it matter? How is it ensured that the melody of `final` ends up in E minor without rewriting it?

## 4. `fuga.py` (the core)

**Flow of the exposition**

```
sujeto(semilla)  →  respuesta (subject + 4 degrees)  →  bajo (subject − 7 degrees)
        ↓
contrapunto(...)  →  contrasujeto   (valid against the answer AND against the bass)
        ↓
contrapunto(...)  →  voz libre (free voice)
        ↓
verificar()  →  render()
```

**Key concepts**
- **Checking grid** (`PASO = 0.5`): the piece is examined every eighth note. `muestrear_midi` returns the pitch sounding at each point of the grid.
- **Consonance** (`CONSONANCIAS`): unison/octave, thirds, fifth and sixths. It is evaluated with the interval class (`semitones mod 12`).
- **Parallels** (`paralelos`): consecutive fifths or octaves with both voices moving in the same direction.
- **Passing tones** (`nota_de_paso`): a dissonance on a weak beat is allowed if the voice that causes it enters by step.
- **Subject generation** (`sujeto`): *rejection sampling*: random candidates are generated and those that break the rules are discarded (starts and ends on the tonic, initial leap, a single climax, closing by step).
- **Counterpoint as backtracking search** (`contrapunto`): it is a constraint satisfaction problem.
  - `dfs(i)` chooses note `i`; `nota_ok(i, g)` checks the rules and **prunes** if they are broken.
  - Candidates are tried in random order (according to `SALTOS` and `PESOS`) so that different seeds give different solutions.
  - `max_nodos` limits the effort; if it runs out, it returns `None` and the caller tries another seed.
- **Scenarios** (`escenarios`): a list of `(displacement, start, partners, previous)`. The generated voice must satisfy the rules **in all of them at once**. That is how the countersubject works against the answer and against the bass (invertible counterpoint), and how, in the episodes, it works in the three repetitions of a sequence.
- **Rules of `contrapunto`:**
  - consonance on every beat (quarter note);
  - dissonance on a weak beat only as a passing tone, neighbor tone or escape tone;
  - no parallel fifths or octaves between consecutive points or between consecutive beats;
  - no voice crossing;
  - leaps of up to a fifth, and after a leap of a fourth or more, stepwise motion in the opposite direction;
  - the first note close to the previous one (`previa`) and the last one inside `triada` (by default, the D minor triad; `triada=None` removes the rule, and other sections pass it the F major triad or the triad of the destination tonic).
- **Retries** (`componer`): it tries successive seeds until the countersubject and the free voice exist; it also demands a countersubject with a melodic profile (≥5 distinct notes and a range ≥4 degrees). That is why `componer(semilla=1)` may return the subject of seed 2.
- **Independent verification** (`verificar`): it runs through the whole piece, voice pair by voice pair, and counts dissonances on the beat and parallels.

**Suggested reading:** constants → `midi` → `colocar` → `muestrear_midi` → `paralelos` → `nota_de_paso` → `sujeto` → **`contrapunto`** (take it slowly: `nota_ok` first, then `dfs`) → `componer` → `verificar` → `tono` and `render`.

**Experiments**
- Add `5` to `CONSONANCIAS` (the fourth) and observe how the character changes.
- Remove the call to `nota_de_paso` and see how many seeds no longer have a solution.
- Change `L` (duration of the subject) or `SALTOS`.
- Call `contrapunto` with `triada=None` to remove the rule on the final note.

**Questions:** why is the grid in eighth notes and not quarter notes? What does the `'<'` mean in a partner? Why does the countersubject need two scenarios? Why are the candidates traversed in random order and not in a fixed order? What does `verificar()` not detect?

## 5. `fuga_larga.py`

**Central concept:** `seccion()` places the (transformed) subject in one voice and **composes the other two against it**, reusing `contrapunto()`.

- **Transformations:** `inversion(voz, eje)` mirrors the melody (`g → eje − g`, contrary motion); `aumentacion(voz, f)` multiplies times and durations.
- **Generation order:** first the **slow** voice (quarter notes) and then the **eighth-note** voice. The fast one can ornament with passing tones; the slow one cannot. The other way round, there was no solution.
- **Nested retries:** if the fast voice finds no solution, another slow voice is tried.
- **Each section is composed separately**, so there may be a parallel at the **join** between two sections. `fuga_larga()` repeats with other seeds until `verificar()` gives zero faults across the whole piece.
- **`PLAN`:** the list of entries `(transformation, voice)`; editing it is the easiest way to change the work.
- **`seccion()` accepts its own `triada` and `rangos`**, needed to write in another key (F major in `fuga_episodios.py`). Its default values reproduce the original behavior.

**Experiments:** edit `PLAN` (add a diminution with `aumentacion(S, 0.5)`); change `RANGO`; change `REG`.

**Questions:** why does it compose the slow voice first? What problem does the retry loop of `fuga_larga()` solve? Why does an inversion in the bass with `eje=0` end up in the right register?

## 6. `fuga_episodios.py`

**Structure (in beats):** exposition 0–24 · episode I 24–34 · entries in F 34–50 · episode II 50–60 · final entries in D 60–84 · final chord.

**Key concepts**
- **Episode** (`episodio`, 10 beats = 6 of sequence + 4 of cadence):
  - *Soprano:* the motif (the first two beats of the subject) repeated three times, each one a degree lower.
  - *Alto:* an eighth-note countermotif **generated only once and valid in all three repetitions** (three scenarios). It is a real sequence: the intervals are identical in scale degrees in each repetition (in semitones they can differ by one, because the shifts are diatonic).
  - *Bass:* quarter notes composed against the other two voices, ending with **dominant → tonic** (or leading tone/subtonic → tonic), which is what makes the arrival sound like a cadence.
- **Modulation to F major:** F major is the relative major of D minor and uses **exactly the same seven notes**. There are no accidentals: the key is asserted by the sequence, the cadence in the bass (C → F), the entries of the subject on F and the arrival chords (`TRIADA_FA`, `TRIADA_RE` fix which notes may close each section).
- **Transpositions by degrees:** `despl=2` takes the subject to F; the inversion in F uses `eje=-5` to start and end on the note F.
- **`fuga_completa()`** chains the plan and retries with other seeds until the whole work verifies.
- **`fuga_completa(semilla, intentos, plan_extra=())`** accepts sections of type `'custom'` with a function of their own `fn(voces, t0, S, sem) -> (voces, duration)`. That is how the stretto (`fuga_stretto.py`) was hooked in without touching the rest.

**Why 10 beats and not 8:** the first version asked for a cadence in only 2 beats and had no solution, because the bass cannot be on the dominant at the same time as the soprano already arrives at the tonic. With 4 beats of cadence (2 of dominant and 2 of tonic) it does.

**Experiments:** `paso=-1` in `episodio` (ascending sequence); `k=2` or `k=4` repetitions; change `base_s`; edit `plan` (for example, one more entry in F).

**Questions:** how do the *scenarios* guarantee that the alto is a real sequence? Why would modulation to the dominant (A minor) require extending the system? What does `TRIADA_FA` fix?

## 7. `midi_export.py`

**Concept:** a piece is a list of notes, and a MIDI file is a list of `note_on` and `note_off` messages with **relative times in ticks** (`PPQ = 480` per quarter note).

- `guardar_midi(pistas, archivo, bpm, segundos=None, fin=None)`: one track per instrument plus a track 0 with the **tempo map**. With `segundos`, the ritardando is translated into tempo changes every quarter note.
- Messages are sorted by tick, and at the same tick the `note_off` messages come **before** the `note_on` ones (this avoids cutting repeated notes).
- Channel 10 (General MIDI percussion) is avoided.
- `CONJUNTOS_FUGA` defines instruments per voice: organ (19), strings (40/41/42: violin, viola, cello) and winds (73/71/70: flute, clarinet, bassoon). For another ensemble: `exportar_fuga(voces, "x.mid", conjunto=[('Oboe', 68), ('Corno inglés', 69), ('Fagot', 70)])` (Oboe, English horn, Bassoon).
- **It does not export:** Kitaro (it is generated in seconds and without an event list), the custom timbres, the humanization, the panning or the reverb. Yanni's cymbal is omitted (it is noise, not a note).

**Questions:** why do the `note_off` messages come before the `note_on` ones at the same tick? What is a delta time? Why is the ritardando passed as tempo changes and not as longer notes?

## 8. `sonidos_naturales.py`

**Flow:** each generator (`olas`, `rio`, `tormenta`...) builds signals from a few basic pieces, mixes them and passes them through `acabar()`, which applies optional reverb, normalization and fades. `guardar()` writes WAV and MP3.

**Basic pieces (read them first)**
- `ruido_color(n, beta, rng)`: noise with a power spectrum ∝ 1/f^β, created by shaping the FFT of white noise.
- `lento(n, rng, tau)` and `rafaga()`: smooth random variation with a time scale `tau`, computed at a low sampling rate and interpolated. It is what moves the water flows, the gusts and the fire.
- `tren(n, rng, tasa)`: Poisson impulses with heavy-tailed amplitude (many small ones, a few large ones). It is the basis of the rain, the crackling of the fire and the storm.
- `burbuja(f0, amp)`: Minnaert / van den Doel model: a damped sinusoid whose frequency rises about 10 % as it dies out, with `f0 ≈ 3.26 / radius(m)` Hz. Large bubbles give low sounds ("gurgles"), small ones high sounds.
- `acabar()`: normalizes by RMS (with a soft limiter capped at 0.9) or by peak (for sparse sounds, like the chimes).

**How each sound is made (in one line)**
- `olas`: a low rumble that grows for ~5 s, crests and decays; the foam is a shorter high-frequency hiss; each wave shifts the panning.
- `agua` (river, stream, waterfall): turbulence + Poisson bubbles with a variable rate. Only the parameters `tasa`, `r_mm`, `grave`, `medio`, `siseo` change.
- `viento_bosque`: the stronger the gust, the brighter the timbre (bands are mixed with exponents that grow with the gust), the more leaves, and a narrow whistle.
- `lluvia_suave`: thousands of micro-impacts per second + medium drops + dripping from leaves (`ping`) + puddle bubbles.
- `tormenta`: the nearness N(t) is an asymmetric Gaussian; far away only the low frequencies sound (the air absorbs the highs) and nearby everything sounds; the center of the storm crosses from left to right and, as it passes overhead, the sound opens up to the whole stereo field. The thunder (`trueno`) is louder the closer it is.
- `campana` / `campanas`: modal synthesis. Metal: partials of a free bar (1; 2.756; 5.404; 8.933) with their own decay. Wood: partials that die out quickly and a dry knock. A gust of wind makes several neighboring chimes collide.
- `fuego`, `goteo_cueva`, `grillos`, `bosque_nocturno`: see the code; they all use the same pieces.

**Experiments:** change `tasa` and `r_mm` in `rio` or `arroyo` and compare; in `tormenta`, move `t_pico`, `wa` and `wd`; in `viento_bosque`, try another `sesgo` in `rafaga`; in `campanas`, replace the notes of `METAL`; change the `beta` of a `ruido_color` (for example, from 2.0 to 1.0 in `olas`) and see how the timbre changes.

**Questions:** why does `lento()` work at 100 Hz and not at 44100? What is the difference between normalizing by RMS and by peak, and why do the chimes use peak? Why does the storm mix bands with different exponents of the nearness? What is the relationship between the radius of a bubble and its pitch?

## 9. `sonidos_meditativos.py`

- **Bowls** (`cuenco`): each of the 4 inharmonic modes (`RATIOS_CUENCO`) splits into two frequencies 0.25 to 1.4 Hz apart; their sum gives slow beating (the "throb"). Struck: each mode decays on its own (the high ones first). Rubbed: continuous excitation, and the high modes enter little by little. The mode ratios are typical values taken from the literature, not measured on a real bowl.
- **Deep sea** (`mar_profundo`): almost everything below 800 Hz: pressure (< 110 Hz), damped distant swell of ~10 s, large bubbles and whale calls (`llamada_ballena`; they are disabled with `ballenas=False`), with a 7 s reverb.
- **Fractal noise** (`fractal`): the slope β changes over time (`curva_beta`: triangular from 0.2 to 2.2 and back). Each 0.74 s segment is noise with its own β, and the segments overlap by half with a sine window, so that the total power is constant. `hurst(β) = (β − 1)/2` and `dimension_fractal(β) = 2 − H` convert the slope into the Hurst exponent and into the fractal dimension of the signal's graph (valid for 1 < β < 3).
- **Binaural** (`binaural`): left ear at `portadora − beat/2` and right ear at `portadora + beat/2`; the `beat` falls from 10 to 4 Hz. The phase is computed with a `cumsum` of the frequency (otherwise the change of frequency would produce phase jumps). It needs headphones.
- **Isochronic** (`isocronico`): a tone whose amplitude pulses at `ritmo` Hz; it works on speakers.

**Experiments:** `beta=(1.0, 1.0)` in `fractal` gives steady pink noise; try `beat=(8, 8)` in `binaural` and measure with `verificar_sonidos.py` that the difference between the ears is 8 Hz; raise the maximum `delta` (in `cuenco`) and observe the speed of the throb.

**Questions:** why use a sine window and not a Hann window when overlapping independent noise segments? Why is it necessary to accumulate the phase in the binaural tones? How is the spectral slope related to the fractal dimension? Why are a bowl's partials inharmonic?

## 10. `verificar_sonidos.py`

Each test measures a property that can in fact be measured:

| Test | Measures |
|------|----------|
| `t_ruido_color` | log-log slope of the spectrum, compared with the theoretical β |
| `t_olas` | median separation between the detected crests |
| `t_agua` | the stream is brighter (spectral centroid) than the river |
| `t_viento` | correlation between level and brightness of the gusts |
| `t_lluvia` | level stability and mean brightness (without the fades) |
| `t_tormenta` | time of the maximum, level rise, growing brightness at the peak and L/R ratio at the start and at the end |
| `t_campanas` | partials at f0·[1; 2.756; 5.404] and that the wood decays faster than the metal |
| `t_fuego` | kurtosis of the high band (impulsiveness) |
| `t_grillos` | dominant carrier and pulse rate |
| `t_cuencos` | modes, beating, 60 dB decay time and rise time of the rubbed bowl |
| `t_mar` | fraction of energy below 800 Hz and level variation |
| `t_fractal` | measured β versus the expected one along the piece |
| `t_binaural` | frequency difference between the ears and leakage of one tone into the other ear |
| `t_isocronico` | pulse rate |
| `t_general` | no NaN, peak ceiling and audible level, in all the pieces |

**What it does not do:** it does not say whether something sounds good. A failing test usually indicates a synthesis or measurement error (see lesson 8). To add a test: write `t_algo()` returning `(ok, message)` and add it to `PRUEBAS`.

## 11. `fuga_stretto.py`

**Flow:** `cadenas_stretto(S)` searches for valid chains of three entries → `seccion_stretto` tries them in order until the whole work verifies → `fuga_con_stretto` chooses the subject.

**Key concepts**
- **Stretto**: entries of the subject with a delay shorter than its duration. For it to be valid, the overlapping voices must satisfy the rules of counterpoint.
- **`chequear_pareja(a, b, a_arriba)`**: rules between two lines already written, at every eighth note where both sound: no crossing, only consonances on the beats, a weak-beat dissonance only if one voice attacks it by step, no parallel fifths or octaves. It returns `(ok, motivo)` — (ok, reason).
- **`pares_validos(S)`**: which (delay, transposition) the subject admits with itself.
- **`cadenas_stretto(S)`**: for three voices, each with the subject `'S'` or the answer `'A'` (transpositions in `OPCIONES`: soprano {S: +7, A: +4}, alto {S: 0, A: −3}, bajo {S: −7, A: −10}), in each order of entry and with delays d = 0 / d / 2d. **Each pair** that overlaps must be valid. They are sorted from smaller to larger delay.
- **Choosing the subject, not just the stretto**: `candidatos_stretto` runs through seeds and keeps those that admit a stretto AND allow the exposition to be composed (`componer(s)[0] == s`). `fuga_con_stretto` builds the fugue with the tightest one.
- **`diagnostico_estricto`**: a review of the whole work that is stricter than `verificar()`.

**Results (with the default seeds)**
- The original subject (seed 2) only admits a delay of 4 beats, and only at the octave.
- Of 300 candidate subjects, 19 admit a delay of 3 beats or less, and 7 of them also allow the exposition to be composed.
- The one from seed 5 was chosen, with a delay of 3 beats (alto, soprano, bass, all with the subject).
- The subject of seed 71 admits, between **two** entries, many delays (1; 2; 2.5; 3; 4...). When chaining **three** entries it only admits 1 beat, and that chain mixes answer and subject (alto with the answer, then bass and soprano with the subject).

**Experiments:** `python fuga_stretto.py --dmin 0.5 --dmax 1` uses a subject with a 1-beat stretto; add positions to `OPCIONES`; widen the range of `cadenas_stretto` to `dmax=6`; use `pares_validos(sujeto(s))` to count how many delays each seed admits.

**Questions:** why must the subject be chosen instead of composing the stretto around any subject? Why does `cadenas_stretto` check all the pairs and not only the consecutive ones? Why does `candidatos_stretto` require that the exposition can be composed with that same subject?

## 12. `fuga_tonal.py` (the longest module)

**Flow:** exposition from `fuga.py` → `a_midi` → seven steps (episode I, two entries in A minor, episode II, two entries in D minor and final cadence), each with its expected key → `verificar_midi`.

**Key concepts**
- **Why MIDI pitches**: D natural minor contains neither G♯ nor C♯, which are the leading tones of A and D minor. With D-minor degrees they cannot be written.
- **`Escala`** (index 0 = tonic) and **`contrapunto_tonal`**: each scenario carries its own scale, and the generated voice is made of relative indices valid in all of them. New rules: the previous note is measured in semitones (≤ 7) and there are no augmented seconds (F → G♯ in harmonic A minor).
- **Real versus diatonic transposition**: the subject in A minor is the D minor one + 7 semitones, which keeps all the intervals and only changes B♭ to B natural. The move to F major in `fuga_episodios.py` used the same degree of another tonic: same notes, different intervals.
- **`episodio_tonal`**: the sequence drops one degree per repetition, and the last repetition is written in the destination scale with a displacement of −4 (D → A) or +4 (A → D) degrees, which compensates for the change of tonic (a fifth is about 4 degrees) so that the pitch keeps going down one degree and does not jump. The alto countermotif is generated once and is valid in the three repetitions even though the last one has another scale.
- **`cadencia`**: it enumerates combinations of notes for three voices and two chords (dominant → tonic) and picks the one with the least movement. Rules: bass on the root, leading tone in an upper voice that rises a semitone to the tonic, tonic chord with root **and third**, consonance among all the voices, no parallels, no augmented seconds.
- **`seccion_tonal`**: like `fuga_larga.seccion`, but in MIDI and with the triad given as pitch classes.
- **`estimar_tonalidad`**: the Krumhansl-Schmuckler algorithm. The duration of each of the 12 pitch classes in a segment is accumulated and correlated with the profile of each of the 24 keys. It is a statistical estimate. **`informe_tonal`** prints it segment by segment together with the time each accidental sounds.
- **The expected key is a selection criterion**: `fuga_tonal()` only accepts a section if its estimated key is the intended one; that is why variants were discarded until variant 8 was found.
- **`render_midi` / `exportar_midi`**: the same as `fuga.render` and `midi_export` but with MIDI pitches.

**Experiments**
- Remove the `esperada` check in `paso()` and see what key the report estimates in each section.
- Use `LA_ARM` (harmonic A minor) in the entries in A minor so that G♯ appears in the generated voices.
- Change `k` and `paso` in `episodio_tonal` or the order of the steps.
- Ask for episode II with the opposite destination (`'La'` instead of `'Re'`) and see what fails.

**Questions:** why does the cadence require the third in the tonic chord? What problem would appear if the sequence moved to the new scale without the ±4-degree displacement? Why does the key estimator get confused in the stretch of the sequences? What changes between a real and a diatonic transposition?

## Design lessons (what failed when testing and how it was solved)

1. **Asking a sustained note to be consonant with everything that moves around it has no solution.** The first version of the free voice failed because of this. The rule was relaxed: a dissonance on a weak beat is valid if the voice that moves enters by step (`nota_de_paso`), as in the Baroque style.
2. **Generation order matters.** In the new sections, with the fast voice composed first there was no solution; with the slow one first, there was.
3. **The joins between sections are a weak point.** Each section is composed separately and parallels can appear between one and the next. Solution: verify the complete work and retry with another seed.
4. **A "valid" countersubject can be boring.** The first one the algorithm found oscillated over two or three notes. A variety filter was added (≥5 distinct notes, range ≥4 degrees).
5. **Cadences need time.** Dominant and tonic cannot sound at once, so each episode lasts 10 beats and not 8.
6. **Randomness needs regularization.** In Winston and Yanni, the first seeds repeated notes or made leaps of a seventh. Repetition and leaps were penalized, and the seed was chosen by reading the melodies and measuring repetitions, maximum leaps and non-chord notes on strong beats.
7. **Normalized volume hides the shape.** In Yanni, the ending barely sounded louder than the rest because the peak (timpani and cymbal) fixed the normalization. The velocities were adjusted per section and the RMS was measured every 10 s.
8. **Measure before adjusting.** The rain test failed because it included the fade-in and fade-out in the stability calculation, but it was interpreted as unstable rain and the generator was retouched unnecessarily. The problem was in the measurement (the real variation was 0.23 dB).
9. **A stretto depends on the subject.** Only 19 of 300 subjects admit a delay of 3 beats or less. The valid chains that were found are almost all at the octave (subject with subject or answer with answer); with the rules used, none appeared that alternates subject and answer, which is what is usual in Bach.
10. **Cadences need a third.** The first version ended on a chord of root and fifth, and the key estimator read it as D major (0.79). Once the third was required, the final cadence is estimated as D minor (0.88).
11. **If the metric is the criterion, the results come out partly by construction.** `fuga_tonal.py` only accepts a section if its estimated key is the intended one. That guarantees that the notes fit, not that it sounds like a modulation.
12. **Real versus diatonic transposition.** Moving to A minor by adding 7 semitones keeps all the intervals; moving to F major by adding 2 degrees keeps the notes but not the intervals. It is the difference between two modulations that can be told apart.
13. **A sequence can cross from one key to another.** It is enough to change the scale of the last repetition and compensate for the change of tonic with ±4 degrees.
14. **With accumulated constraints, what fails is the generation order or the size of the cadence.** It already happened in the fugue (slow voice first, a 4-beat cadence); in `fuga_tonal.py` the cadence is solved by enumeration instead of by search.

## Known limitations and next ideas

**Limitations**
- In `fuga.py` the answer is the subject moved **+4 degrees within D natural minor** (a diatonic transposition: same notes, intervals that can change by a semitone). It is neither an exact transposition nor Bach's *tonal answer*.
- In the MIDI, **all the notes have the same velocity** (0.7): the strings will sound flat.
- **Duplicated code**: `wav_a_mp3` appears in four files (`fuga_larga.py`, `winston.py`, `kitaro.py`, `yanni.py`), and there are several versions of `hz`, of the piano synthesis (nearly the same in Winston and Yanni) and of `reverb`. A candidate for a common module (`audio.py`).
- No formal **unit tests**.
- `fuga_tonal.py` **does not integrate the stretto or the section in F major**; they are separate versions.
- The entries in A minor use natural minor; **G♯ and C♯ appear only in the cadences**. The inversion in A minor is diatonic, not chromatic.
- The strettos found are almost all **at the octave**; it remains to be tested whether alternating subject and answer is impossible with these rules or only with these transpositions.
- The augmentation in D minor is the stretch with the weakest key in `fuga_tonal.py` (D minor 0.69 versus G major 0.68).
- **Real time**: everything is generated whole at once. Converting it to blocks requires state between blocks (filters, phases) and replacing the FFT noise and the convolution reverb with recursive or block-based solutions. No prototype.
- **Synthesized timbres** of flute, clarinet, bassoon and strings for the fugue's audio: they exist only as MIDI programs.
- Kitaro is not exported to MIDI.

**Ideas**
- A dynamic profile in the MIDI (crescendo toward the climaxes and in the sequences).
- An entry of the subject on the subdominant.
- A tonal answer, as in Bach, instead of the diatonic transposition at the fifth.
- Refactor Kitaro to collect events and be able to export it to MIDI.
- Extract the common code into `audio.py` and write tests (for example, that `verificar()` detects a parallel fifth put there on purpose).
- A live-playback prototype with `sounddevice` (rain, wind, binaural, bowls, chimes) with live controls.
- Combine stretto and modulation to the dominant in a single work.
- A modulation to other keys (`destino` currently only accepts `'La'` and `'Re'`).
- Birds, frogs and sea with strong surf among the sounds.
- Replace additive synthesis with a SoundFont (FluidSynth).

## Glossary

**Musical**
- **Canon:** a melody that imitates itself with a delay (and sometimes transformed).
- **Fugue:** a contrapuntal form built around a theme (the subject) that enters successively in each voice.
- **Subject:** the theme of the fugue. **Answer:** the subject transposed to the fifth. **Countersubject:** the melody that accompanies the subject when another voice enters.
- **Exposition:** the first part of the fugue, where all the voices enter. **Episode:** a passage between entries of the subject, made from fragments of the theme.
- **Sequence:** repetition of a melodic shape at another pitch (e.g. one degree lower each time).
- **Inversion (contrary motion):** a mirror of the melody; what goes up, goes down. **Augmentation:** the same melody with its durations multiplied.
- **Invertible counterpoint:** two voices that remain correct when they swap position (the upper one goes below).
- **Cadence:** a harmonic closing. **V–I:** dominant → tonic. **VII–i:** subtonic → tonic (in natural minor).
- **Tonic, dominant:** the first degree of the scale, and the fifth.
- **Relative major:** the major key that shares its notes with the minor (F major with D minor).
- **Modulation:** a change of tonal center. **Sustain pedal:** the piano pedal that lets the notes ring.
- **Strong / weak beat:** position within the bar (in 4/4, beats 1 and 3 are strong).
- **Passing tone, neighbor tone, escape tone:** brief dissonances on a weak beat, accepted by theory because they are approached or left by step.
- **Parallel fifths/octaves:** two voices moving together while keeping an interval of a fifth or an octave; they are avoided because the voices lose independence.
- **Pentatonic:** a five-note scale (D, F, G, A, C).
- **Stretto:** entries of the subject that begin before the previous one has finished.
- **Dominant:** the key built on the fifth degree (A minor with respect to D minor); also, the chord on the fifth degree.
- **Leading tone:** the note a semitone below the tonic that tends to rise to it (G♯ in A minor, C♯ in D minor).
- **Harmonic minor:** a minor scale with the seventh degree raised (the leading tone).
- **Authentic cadence (V–i):** dominant → tonic, with the leading tone rising to the tonic.
- **Real / diatonic transposition:** the real one moves all the notes by the same number of semitones and keeps the intervals; the diatonic one moves them by the same number of scale degrees and can change their quality.
- **Dominant chord, tonic chord:** the chords on the fifth and the first degree.
- **Pivot chord:** a chord common to two keys, which serves as a bridge when modulating.
- **Tibetan bowl:** a metal object with inharmonic vibration modes that sounds when struck or rubbed.
- **Beating:** a slow variation of volume that results from adding two sounds of almost equal frequency.

**Technical**
- **Additive synthesis:** building a sound by adding sinusoids (partials).
- **LFO:** a low-frequency oscillator that modulates another parameter.
- **Convolution / convolution reverb:** simulating a room by convolving the signal with its impulse response.
- **ADSR / envelope:** how the volume of a note evolves (attack, sustain, release).
- **Backtracking:** exploring solutions step by step, undoing the last decision when a dead end is reached.
- **CSP (constraint satisfaction problem):** finding values that satisfy all the rules at once.
- **Rejection sampling:** generating random candidates and discarding those that do not satisfy the rules.
- **Seed:** the initial value of the pseudorandom generator; same seed, same result.
- **Ticks / PPQ:** the unit of time of a MIDI file and its resolution (pulses per quarter note).
- **General MIDI program:** a number (0–127) that identifies a standard instrument.
- **1/f^β noise (colored noise):** noise whose power decays as 1/f^β; β = 0 white, 1 pink, 2 brown.
- **Hurst exponent (H) and fractal dimension:** for a fractional Brownian motion, the slope is β = 2H + 1 and the graph has dimension D = 2 − H.
- **Poisson process:** independent events with an average rate per second; it models drops, crackles and bubbles.
- **Minnaert bubble:** a physical model of the air bubble in water: it resonates at a frequency inversely proportional to its radius.
- **Modal synthesis:** adding the vibration modes of an object, each with its own frequency and decay.
- **Binaural tone:** two tones of almost equal frequency, one per ear; their difference (the beat) exists only in perception.
- **Isochronic tone:** a tone that pulses at a fixed rate; it works on speakers.
- **Overlap-add:** building a long signal from segments that overlap; with a sine window and independent segments the total power is constant.
- **Krumhansl-Schmuckler:** an algorithm that estimates the key of a passage by correlating the duration of each pitch class with 24 profiles (12 major and 12 minor).
- **Spectral centroid:** the "mean frequency" of the spectrum; it measures the brightness of a sound.
- **Kurtosis:** a measure of how impulsive a signal is; Gaussian noise has kurtosis 3.
- **RMS:** the root-mean-square value of a signal, the usual measure of its average volume.
